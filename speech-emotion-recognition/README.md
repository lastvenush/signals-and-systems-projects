## 📂 Project Directory

This repository contains a collection of signal processing and systems analysis projects. Each directory includes its own source code and detailed documentation.

### 🎙️ Featured Project: Speech Emotion Recognition (Phase 1)
*   **[Speech Emotion Recognition](./speech-emotion-recognition/)**: A machine learning project that classifies 5 different emotions using time-domain features (ZCR, STE, Pitch).
    *   **Accuracy:** %35.50 (Validated with a 200-sample test set).
    *   **Highlights:** Modular architecture, feature scaling, and class balancing.[cite: 2]
