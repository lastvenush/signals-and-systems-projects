# Signals and Systems Projects

This repository contains Python implementations developed for the **Signals and Systems** course.

## Projects

### 1️⃣ Sinusoidal Signal Sampling
Generation, sampling, and visualization of sinusoidal signals based on the Nyquist sampling theorem.

**Topics**
- Signal generation
- Sampling
- Nyquist criterion
- Signal visualization

---

### 2️⃣ DTMF Signal Generator
Implementation of Dual-Tone Multi-Frequency (DTMF) signals used in telephone keypads.

**Topics**
- Frequency synthesis
- Signal generation
- Dual-tone signals
- Time-domain visualization

---
### 3️⃣ Signal Encoding and Decoding
Implementation of encoding and decoding algorithms used for signal representation and recovery.

Featured Project: Speech Emotion Recognition (Phase 1)
Speech Emotion Recognition: A modular machine learning system that classifies five different emotions from audio signals using time-domain features.[cite: 1, 2]

Features Used: ZCR (Zero Crossing Rate), STE (Short-Time Energy), and Pitch.[cite: 2]

Model: Random Forest Classifier with feature scaling and class weight balancing.[cite: 2]

Performance: Achieved 35.50% Accuracy on a strictly separated test set (200 samples), ensuring no overfitting.[cite: 2]

Tech Stack: Python, Librosa, Scikit-learn, Pandas.[cite: 1, 2]
